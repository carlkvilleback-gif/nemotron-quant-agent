# Demo video script (under 3 minutes)

Narration text for the voice is in `narration.txt`. Record the screen without sound, then lay the voice on top.
Before recording: open https://nemotron-quant-researcher.streamlit.app in full screen and wake it up.

| Time | What to show on screen | Narration (same text as narration.txt) |
|---|---|---|
| 0:00–0:08 | The app's start page | "Most trading ideas look amazing in a backtest. So I built an AI agent that tries to prove them wrong." |
| 0:08–0:18 | Slowly scroll the title and example buttons | "This is Nemotron Quant Researcher. You give it an idea, or it finds one in today's market news…" |
| 0:18–0:30 | Click **QQQ in a panic**, pick **0.3%**, press **Run research**, show the spinner | "Let me show you. I click an example, pick my trading cost, and press run." |
| 0:30–0:58 | Scroll to the **TLT** report: the blue reviewer box | "Under the hood, Nemotron Super… a second agent reviews it. Here it caught a real bug…" |
| 0:58–1:10 | Open **Code the agent wrote** | "The code runs in a sandbox without any API keys…" |
| 1:10–1:35 | **Micron overnight** report: the 💸 trading-cost box and its table | "Now the honest part. Overnight trading in Micron returned over four thousand percent…" |
| 1:35–2:00 | **RSI-2** or **Gold** report: robustness table (Fragile) | "And when an idea does beat the S and P five hundred, the agent checks if it was just luck…" |
| 2:00–2:15 | Scroll up to the **Leaderboard**, move the cost slider | "Every idea lands on a leaderboard…" |
| 2:15–2:30 | GitHub: the **Actions** tab with the daily runs, then README | "Every weekday morning it runs completely by itself…" |
| 2:30–2:45 | Back to the app, the new report from your run at 0:18 | "Most ideas come back weak. That's the point…" |

Tips
- Record with the Xbox Game Bar (Win + Alt + R) or OBS; 1080p is plenty.
- If the run at 0:18 is still going, cut away and come back to it at the end.
- Upload to YouTube as **Public**, no copyrighted music.
